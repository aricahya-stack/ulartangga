# Models

Versi 3.0 tidak membutuhkan GLB untuk papan, pion, ular, tangga, atau dadu. Semua bentuk utama dibuat procedural oleh PlayCanvas Engine agar ukuran, animasi, material, dan koneksi antarpetak dapat dikontrol langsung dari TypeScript.

Folder ini sengaja dipertahankan untuk aset GLB tambahan di masa depan. Gunakan hanya model buatan sendiri, CC0, atau aset dengan lisensi yang secara eksplisit mengizinkan penggunaan proyek.
